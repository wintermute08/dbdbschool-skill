# 디비디비 스킬

디비디비스쿨의 늘봄·방과후학교 업무를 돕는 한국어 Codex 스킬입니다. 제공된 HWP 매뉴얼 14개를 바탕으로 관리자·강사·담임·학생/학부모가 필요한 업무만 찾아 읽도록 구성했습니다.

비공식 프로젝트이며 엑스메카 또는 디비디비스쿨이 배포·보증하는 제품이 아닙니다. 학교 계정, 서비스 API, 무인 매크로를 제공하지 않습니다. 실제 서비스 작업에는 사용 환경의 연결 도구와 학교의 해당 권한이 필요합니다.

## 포함된 업무

- 강좌 설정, 선착순·대기·추첨, 다음 달 준비
- 신입생 가학적, 재학생 진급, 신청 이력의 학적 동기화
- 분기 접수 후 월별 비용 관리
- 수강료 산출, 지원금 정산, 환불 후 재정산
- 나이스·에듀파인·행정실 자료 출력
- 온라인 출석부, 귀가일정, 결석·조기귀가
- 문자·푸시, 설문과 집계
- 연말 백업과 초기화 범위 점검

## 설치

이 저장소를 내려받은 뒤 저장소 루트에서 실행합니다. 기존 설치가 있으면 자동 덮어쓰지 않습니다.

```bash
python3 scripts/install_skill.py
```

기본 설치 위치는 `${CODEX_HOME:-$HOME/.codex}/skills/dbdbschool`입니다. 다른 위치에서 내용을 검토하려면 대상 skills 디렉터리를 지정합니다.

```bash
python3 scripts/install_skill.py --skills-dir /path/to/skills
```

설치 후 새 Codex 대화의 스킬 목록에서 `dbdbschool`을 확인하세요. 스킬을 직접 호출하거나 디비디비스쿨 관련 업무를 요청할 수 있습니다.

```text
$dbdbschool 1분기 신청을 받은 뒤 월별로 나눠 관리하는 절차를 정리해 줘.
$dbdbschool 신입생 가학적을 본학적으로 바꾼 뒤 확인할 항목을 알려줘.
$dbdbschool 환불 완료 후 지원금과 행정실 파일을 어떻게 확인해야 해?
$dbdbschool 담임용 미신청자 조회 안내를 작성해 줘.
```

설명·초안·파일 작성·실제 시스템 반영을 구분하며, 이미 구체적으로 승인된 업무는 반복 확인하지 않도록 설계했습니다. 데이터 삭제, 발송, 권한 변경 등의 실행은 요청 범위와 연결 도구의 규칙을 따릅니다.

## 검증

```bash
python3 -m unittest discover -s tests -v
python3 scripts/validate_package.py
```

검증은 배포 구조·참고자료 연결·설치 동작을 확인합니다. 실제 학교의 로그인·추첨·징수·문자 발송을 실행하는 테스트는 포함하지 않습니다. 행동 검토 사례는 [evals/scenarios.md](evals/scenarios.md)에 있습니다.
