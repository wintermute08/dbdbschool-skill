# 설정·강좌·접수·추첨

근거: 제공 매뉴얼 01의 2–7·10장, 11. 원본 목록은 [sources.md](sources.md).

## 처음 운영할 때

학교 전용 서비스 주소를 학교 홈페이지 배너 또는 관리자 학교관리에서 확인한다. 서비스 관리자와 담임은 교직원 탭, 강사는 강사 탭을 사용한다. 교직원 등록과 강사 등록은 별도다. 필요한 업무에 맞는 계정 권한을 사용한다.

학생 → 필요한 교직원 → 강사 → 강좌 순서로 준비하고 신청기간을 설정한다. 강사가 아직 없어도 강좌 개설이 가능한 경우가 있으므로 불필요하게 중단하지 않는다. 일괄입력은 현재 화면의 샘플을 내려받는다.

`환경설정 > 기본설정`에서 필요한 기능을 확인한다. 강좌구분은 월·분기를 구분하는 운영 단위다. 접수 단위와 정산 단위가 다르면 [monthly-operations.md](monthly-operations.md)를 읽는다.

## 강좌 입력의 연결 관계

- 강좌명 기준 일괄입력이 기존 강좌 정보를 수정할 수 있다. 선택한 구분과 동명 강좌를 점검하고 신규 등록인지 갱신인지 구분한다.
- 강사 ID는 담당자 연결뿐 아니라 강사 기준 징수·설문 집계 단위다. 이름만 같다고 ID를 합치거나 기존 ID를 임의 분리하지 않는다.
- 요일·시간은 등록된 강의시간을 사용한다. 제공본 형식은 `월:13:00~13:40`, 같은 날 여러 시간은 쉼표, 여러 요일은 공백으로 구분한다. 업로드 샘플과 현재 설정에 맞춘다.
- 시간 방식은 요일과 실제 시간 겹침을, 코드 방식은 동일한 코드명을 기준으로 검사한다. 코드만 다르면 실제 시간이 겹쳐도 제대로 막지 못할 수 있다.
- 수강료와 수용비, 교재비, 재료비는 구별한다. 강좌 금액 변경 후 학생 금액에 반영하려면 해당 신청자 금액 일괄적용이 필요하다. 개별 조정액이 덮어써지는지 먼저 비교한다.

## 강좌 상태와 마감

| 상태 | 학생 신청 화면 | 신청기간 중 신청·취소 | 제한 검사 |
|---|---|---|---|
| 출력 | 표시 | 가능 | 설정에 따라 검사 |
| 종료 | 표시 | 불가 | 중복 검사에 포함 |
| 대기 | 표시 안 됨 | 불가 | 제공본상 신청 제한 대상에서 제외 |

`강사마감`은 강사의 수강생·금액 변경을, `환불마감`은 학생·강사의 환불 신청을, `출결마감`은 해당 날짜의 강사 출결 수정을 제한한다. 서로 대체하지 않는다.

징수 자료 확정 전 강사 조정을 끝내고 강사마감 Y·강좌 종료를 확인한다. 과거 강좌를 새 접수 화면에서 숨길 때 대기를 고려한다. 중복 검사에서 빠지는 영향도 점검한다.

## 신청이 안 될 때

학교·학생 학적과 강좌구분을 확인한 뒤 신청기간(학년별 설정 포함), 출력 상태, 대상학년·학과, 정원·대기정원, 신청 개수 제한, 시간 중복, 중복제한그룹, 강사 ID 중복을 순서대로 좁혀 본다. 제한 범위가 같은 강좌구분인지 등록된 모든 강좌인지 확인한다. 신청 시작 시간이 지났다면 새로고침 후 상태를 확인한다. 문제를 해결하려고 모든 제한을 한꺼번에 해제하지 않는다.

## 대기와 추첨

- 선착순과 추첨제를 먼저 구별한다. 추첨제는 정원 초과 접수 후 선정하며, 미선정자는 순번이 있는 대기자로 이동한다. 대기정원이 0이어도 추첨 결과로 늘어날 수 있다.
- 결원 충원은 실제 대기순번과 학교 운영 규칙을 확인해 `대기자관리 > 신청`으로 전환한다. 대기자가 있는 강좌에 신규 신청자를 직접 넣어 순번을 건너뛰지 않는다.
- 추첨 전 접수 마감, 정원, 우선추첨 대상, 자유수강권 우선 옵션, 학생별 추첨선정개수제한을 확인한다. 선정개수제한에 걸리면 미달 강좌도 대기자가 될 수 있다. 우선순위나 자격을 스킬이 결정하지 않는다.
- `추첨제관리 > 추첨` 실행 후 `추첨결과`에서 선정·대기 인원과 순번을 조회·보관한다. 이미 실행된 추첨을 단순 확인 목적으로 재실행하지 않는다.
- 2차 추첨은 기존 선정자를 우선추첨대상자로 보존한 뒤 대상 강좌의 추첨완료 상태를 N으로 바꾸고 추가 접수·추첨한다. 추가 접수 전에 기존 신청자 지정 여부를 확인한다.
- 2차를 선착순으로 받을 때는 추첨제의 `사용안함(선착순 신청)` 의미를 실제 설정에서 확인하고 접수기간을 조정한다. 기존 선정·대기 자료를 초기화하지 않는다.

확인: 강좌별 접수/대기/정원, 학생별 신청조회, 복사 대상의 중복 유무, 마감 및 상태가 의도와 일치해야 한다.
