# 학생·학부모·강사·담임 안내

근거: 제공 매뉴얼 20, 30, 40 및 11. 사용자 역할에 필요한 메뉴만 안내한다. 학교가 비활성화한 기능은 보이지 않을 수 있다.

## 학생·학부모

학교의 실제 방과후학교 배너/서비스로 접속하고 학생 탭에서 학교가 안내한 학적과 본인 비밀번호를 사용한다. 신입생 임시학적은 [enrollment.md](enrollment.md)를 확인한다. 예전 매뉴얼의 공통 초기 비밀번호를 현재 계정 비밀번호로 단정하지 않는다.

- 수강신청: 기간·대상 강좌 확인 → 필요하면 시작 시각 이후 새로고침 → 신청 → 결과 메시지와 신청조회 확인. 추첨 접수는 선정 확정이 아니다.
- 취소: 신청기간의 취소 기능과 이후 환불/취소신청을 구분한다. 환불은 [refunds.md](refunds.md)의 상태를 따른다.
- 신청조회: 강좌구분을 선택하여 내역을 확인하고 필요하면 수강신청서 PDF·시간표를 출력한다.
- 대기신청조회: 대기 내역과 학교가 허용한 순번을 확인한다.
- 출석부조회·지원금조회: 본인 해당 정보와 선택 구분을 확인한다.
- 결석/귀가신청: 유형·일자·사유를 작성한다. 주간 귀가일정과 일자별 예외는 [attendance.md](attendance.md).
- 설문참여·알림보기: 학생/학부모 참여 유형과 실제 참여 가능한 설문을 확인한다.

로그인 실패는 학교·탭·현재 학적·이름 표기·변경 비밀번호를 좁혀 확인한다. 다른 학생을 검색해 로그인하거나 비밀번호를 반복 추측하지 않는다. 학교가 제공하는 찾기 또는 담당자 절차로 연결한다.

## 강사

강사 탭에서 배정된 ID로 접속한다. 수강생관리에서 강좌구분·강좌를 고른 뒤 요청된 학생·비용만 처리한다. 일괄 금액 편집은 화면의 적용과 전체수정 저장을 구별하고 재조회한다. 이전·현재 강좌의 추가/취소자조회로 변동을 비교할 수 있다.

수강생 등록·삭제·이동·금액 수정이 안 되면 강사 권한과 강사마감을 확인한다. 새 강좌 등록과 상세 필드 편집은 별도 권한이다. 제공본의 확대된 강좌 편집 조건은 강사편집 Y, 강좌상태 대기, 강사마감 안함의 조합이다. 기본 설명·첨부 편집과 혼동하지 않는다. 관리자 승인을 우회하려고 마감이나 권한을 바꾸지 않는다.

대기자 전환은 순번과 결원을 확인한다. 출결은 [attendance.md](attendance.md), 환불 확인은 [refunds.md](refunds.md), 문자는 [communications.md](communications.md)를 사용한다.

학기 중 강사 교체는 새 강사 등록 후 대상 강좌의 담당 ID를 연결하는 방식이다. 기존 신청자료를 삭제하여 해결하지 않는다. 강사 ID 기준 집계와 이전 기록에 미치는 영향을 확인한다.

## 담임

교직원 탭으로 접속하여 `학급신청자조회`에서 강좌구분과 학생을 확인한다. 학생별 시간표, 강좌기준 신청자 출력, 반 신청현황, 미신청자 출력, 수강신청서 PDF를 목적에 맞게 사용한다.

학생 비밀번호 정정은 권한이 있는 `학급학생관리`에서 해당 학생을 확인한 뒤 학교의 현재 절차로 수행한다. 한 학생의 로그인 문제 때문에 전체 학생 비밀번호를 초기화하지 않는다. 인증정보 변경이 도구에서 사용자 직접 수행을 요구하면 해당 단계만 인계한다.
