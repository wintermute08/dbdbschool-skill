# 환불과 지원금 재정산

근거: 제공 매뉴얼 01의 9장, 03, 30. 실제 지급이나 환불 규정의 법률 판단을 대신하지 않는다.

## 접수 조건과 계산

학생·강사·관리자 중 요청 역할, 강좌구분·운영월, 마지막 수강일, 실제 수강시수, 전체시수, 비용 항목별 원금, 이미 환불한 금액, 적용할 학교 규정을 확인한다.

`환경설정 > 기본설정`의 환불 기능, 학생신청 허용 여부, 강좌의 환불마감 상태를 점검한다. 강사마감 해제만으로 환불신청이 가능해지는 것으로 설명하지 않는다.

분할·일할은 강좌 총시수와 실제 수강시수가 필요하다. 분할 경계와 원 단위 조정은 학교에 설정된 기준을 사용한다. 기타 방식은 확인된 금액을 직접 입력한다. 교재비·재료비 환불은 각각 별도 입력하며 수강료 환불 비율을 자동으로 복제하지 않는다. 제공본의 질병 예시를 모든 학교의 현재 규정으로 일반화하지 않는다.

## 상태와 반영

| 상태 | 의미와 확인 |
|---|---|
| 접수 | 신청 등록 상태. 학생의 신청 취소 가능 범위는 강사확인 전인지 현재 화면에서 확인 |
| 강사확인 | 강사가 시수·금액 등을 확인한 상태. 최종 정산 완료가 아님 |
| 처리완료 | 관리자가 확정한 상태. 신청자관리 금액에 환불 후 금액이 반영되는지 재조회 |

`환불관리`의 대상 신청을 열어 입력을 검토하고 승인 범위에서 상태를 변경한다. 비고는 학생에게 보일 수 있으므로 내부 메모나 다른 학생 정보를 넣지 않는다. 완료 후 항목별로 변경 전 금액−해당 환불액=변경 후 금액인지 확인한다. 중복 환불·음수·원금 초과는 먼저 해결한다.

## 지원금이 이미 처리된 환불

현재 제공본은 완료된 해당 환불에서 `지원금 처리 다시 하기(자동계산)`를 사용해 건별 재정산하는 방식을 우선 안내한다. 일부 문단은 자동정산이라고 표기하므로 실제 버튼을 확인한다.

전체 `수강자 가져오기`는 환불로 늘어난 잔액의 배분을 바꾸어 다른 강좌의 기존 징수 내역까지 변경할 수 있다. 건별 기능이 없거나 이전 월의 연쇄 재정산이 필요할 때에는 이전 결과를 보관하고 해당 월부터 시간 순서로 처리할 범위를 정한다. 전체 재계산을 무조건 반복하지 않는다.

환불 후 신청자 금액, 해당 지원금 사용액·잔액, 수익자 부담, 관련 후속 월을 비교하고 행정실 출력이 다시 필요한지 정리한다. 분기 중 취소는 각 운영월의 환불 건을 확인한다.

## 잘못 완료한 환불의 정정

제공본상 **처리완료 환불을 삭제해도 신청자 금액이 자동 복원되지 않는다**. 삭제를 원상복구 수단으로 사용하지 않는다. 원거래·환불·현재 금액을 확보하여 정정할 금액과 지원금 재정산 범위를 정한 뒤 권한 있는 절차로 수정한다. 삭제 자체의 승인·도구 제한도 따른다.
