# 출석·귀가·결석·조기귀가

근거: 제공 매뉴얼 04, 07, 20, 30.

## 기능과 역할

관리자가 `환경설정 > 기본설정`에서 온라인 출석부, 귀가일정표, 결석/조기귀가 신청 사용 여부를 확인한다. 강사는 담당 강좌의 출석부, 학생/학부모는 본인의 신청과 조회, 관리자는 전체 운영 조회를 사용한다.

## 출석부 작성

1. `출석부관리`에서 강좌구분·강좌·기준일자를 확인한다. 오늘 날짜 기본값을 과거 출석 입력에 그대로 쓰지 않는다.
2. 실제 출결 근거에 따라 학생별 상태와 비고를 입력한다. 전체출석 선택 기능이 있어도 출석 사실을 추정하지 않는다.
3. `출결상태 전체적용` 등 출결 저장을 실행하고 다시 확인한다.
4. 입실·퇴실시간, 교육내용, 관리·안전 확인 항목을 실제 기록에 맞게 작성한다. 강사 확인 저장과 출결 상태 저장은 별도일 수 있다.
5. 해당 날짜의 처리가 끝났을 때 출결마감을 적용한다. 마감 뒤 강사는 그 날짜를 수정할 수 없으므로 이미 마감된 출석 정정은 관리자 절차를 확인한다.

## 귀가 정보의 우선순위

학생/학부모는 `귀가일정표`에서 요일별 기본 계획을 작성하고 `결석/귀가신청`에서 특정 날짜의 결석·조기귀가를 등록한다. **해당 일자 신청이 있으면 주간 기본 계획보다 우선 표시**된다. 날짜·운영기간을 확인하여 강사 화면과 학생 시간표를 대조한다. 등록된 계획만 보고 실제 인계·귀가 완료를 단정하지 않는다.

관리자는 `귀가일정표`, `결석/귀가신청`의 검색결과를 출력할 수 있다. 강사는 수강생관리에서 학생 이름으로 개별 시간표를 확인하고 선택 강좌의 시간표를 출력할 수 있다. 제공본은 시간표·출석부 버튼 명칭이 혼재하므로 실제 출력 미리보기로 용도를 확인한다.

관리자 시간표는 신청자관리의 학생 시간표용 출력 구분 또는 시간표 PDF 출력에서 강좌구분·학년·귀가정보 포함 여부를 선택한다. 출력물에 보호자 연락처·귀가 방식이 포함되면 전달 대상을 확인한다.

출석 저장과 알림 발송은 별도다. 발송 요청이 있으면 [communications.md](communications.md)를 읽고 수신자·날짜·내용을 대조한다.
